# Core Reusable UI Components Catalog

All shared atomic UI elements in `components/`:

- **`CachedImage.tsx`**: High-performance image loader with local memory/disk caching for avatars and question images.
- **`CustomAlert.tsx`**: Consistent cross-platform modal alert dialog.
- **`DateTimePickerBottomSheet.tsx`** & **`DobPickerBottomSheet.tsx`**: iOS/Android bottom-sheet pickers for test schedules and student birth dates.
- **`InAppNotification.tsx`**: Floating toast banner for real-time announcements.
- **`LiveTestCard.tsx`**: Animated test countdown card with active participant count.
- **`OfflineBanner.tsx`**: Network status bar that appears when internet connection drops.
- **`PremiumButton.tsx`**: Haptic-feedback button with gradient and loading states.
- **`WheelPicker.tsx`**: Smooth scroll wheel selector for test durations and numerical questions.
